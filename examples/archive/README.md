# Research Pilot Example Archive

This directory keeps source fixtures that are no longer part of the first-run
example workspace but remain useful for migration, compatibility tests, and
seed imports.

Tracked archive content:

- `seed-workspaces/`: reusable seed workspaces used by `research_pilot_init.py`.
- `legacy-demo-fixtures/`: older small fixtures used by compatibility tests.

Ignored local archive content:

- `smoke-runs/`: temporary workspaces created during manual verification.
- `generated-dashboard/`: generated dashboard read models.
- `empty-dirs/`: placeholders from local cleanup.
- `macos-metadata/`: local filesystem metadata.
