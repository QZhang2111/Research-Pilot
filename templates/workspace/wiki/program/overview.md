# Research Program Context

This folder is an agent context layer for long-term research taste and north-star notes.

It is not graph truth, not evidence, not a project decision source, and not a project binding system.

Agents may read this context to understand how the user thinks about research direction. Agents must not make decisions for the user from this context, must not treat it as evidence, and must not copy it into project graph truth.

Use this folder for durable taste, north-star framing, research style, and background preferences that help conversation start from the user's real context.
