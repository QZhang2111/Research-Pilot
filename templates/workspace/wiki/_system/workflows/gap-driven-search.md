# Gap-Driven Search

Purpose: turn a Project Gap Analysis evidence need into a targeted paper-search contract.

Search contracts and leads are not graph truth and not Zotero approval.

## Boundary

This workflow must not append graph events, approve papers, or promote candidates.

Source intake is source-agnostic. Zotero = optional adapter. Candidate leads require source intake before project use.

## Status

Public MVP documents the workflow boundary. Search tooling is extracted after graph gap and next-action commands stabilize.
